条件结构

conditions · 让程序会思考
if / else if / else 条件判断

从上往下依次判断，哪个条件先为 true 就执行哪个分支；都不满足走 else。

var score = 82;
if (score >= 90) {
    console.log("优秀");
} else if (score >= 80) {
    console.log("良好");
} else if (score >= 60) {
    console.log("及格");
} else {
    console.log("不及格");
}
switch / case 多分支

当判断某个变量"等于"不同值时，switch 比 if 链更清晰。记得加 break，否则会穿透。

var day = 3;
switch (day) {
    case 1: console.log("周一"); break;
    case 2: console.log("周二"); break;
    case 3: console.log("周三"); break;
    case 4: console.log("周四"); break;
    case 5: console.log("周五"); break;
    default: console.log("周末");
}
三元运算符 ? : 简写

if/else 只有一句话时，可以压缩成一行：条件 ? 真值 : 假值。

var age = 20;
var tip = age >= 18
    ? "成年"
    : "未成年";
console.log(tip);

var num = 7;
console.log(
    num % 2 === 0 ? "偶数" : "奇数"
);

循环结构

loops · 让程序重复劳动
for 循环 最常用

三段式：初始化；条件；更新。已知循环次数时首选。这里求 1 到 10 的和。

var sum = 0;
for (var i = 1; i <= 10; i++) {
    sum += i;
}
console.log("1~10 的和：" + sum);

// 倒序输出 5 1
for (var j = 5; j >= 1; j--) {
    console.log(j);
}
while 循环 条件先判断

先判断条件，为 true 才执行循环体；可能一次都不执行。适合不知道要循环多少次的场景。

var n = 1;
while (n < 100) {
    n *= 2;
    console.log(n);
}
do...while 循环 至少跑一次

先执行一次循环体，再判断条件。无论条件真假，循环体至少会跑一遍。

var i = 3;
do {
    console.log("倒计时：" + i);
    i--;
} while (i > 0);
console.log("发射！");

// 即使条件一开始就是 false，也会进一次
var x = 0;
do {
    console.log("do-while 至少执行一次");
} while (x > 0);
for...of 遍历数组 ES6+

直接拿到元素本身，不用下标。最干净的数组遍历方式（不能直接取到下标）。

var fruits = ["苹果", "香蕉", "橙子"];
for (var fruit of fruits) {
    console.log("吃到了：" + fruit);
}
for...in 遍历对象 遍历键名

专门用来遍历对象的可枚举属性（键名 key）。不推荐用来遍历数组，顺序可能乱。

var user = {
    name: "吕墨涵",
    age: 20,
    major: "计算机"
};
for (var key in user) {
    console.log(key + " = " + user[key]);
}
break 与 continue 跳出 / 跳过

break 直接结束整个循环；continue 跳过这一次，进入下一次。这里用它来打印 1~10 中除了 7 的倍数以外的数。

for (var i = 1; i <= 15; i++) {
    if (i === 12) {
        console.log("遇到 12，break 退出");
        break;
    }
    if (i % 3 === 0) {
        continue;
    }
    console.log(i);
}
