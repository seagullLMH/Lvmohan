CSS 长度单位演示

1. px（像素，绝对单位）

最常用的长度单位，1px 表示一个屏幕像素点，不随其他元素或浏览器设置变化。

width: 100px; width: 200px; width: 400px;
100px
200px
400px

2. %（百分比，相对单位）

相对于父元素的宽度（或高度）计算，常用于做自适应布局。

width: 25%; width: 50%; width: 100%;
25%
50%
100%

3. em（相对单位）

相对于当前元素的 font-size 计算。若用在 font-size 上，则相对其父元素的 font-size。默认 1em = 16px。

font-size: 16px; font-size: 1em; font-size: 2em; font-size: 3em;

父元素 font-size: 16px（基准）

1em = 16px

2em = 32px

3em = 48px

4. rem（相对单位）

相对于根元素 html 的 font-size 计算，不受父元素影响，比 em 更易控制。

html { font-size: 16px; } /* 1rem = 16px */

外层 font-size: 10px，1rem 仍 = 16px

2rem = 32px

5. vw / vh（视口相对单位）

vw 相对于浏览器视口宽度（1vw = 视口宽的 1%），vh 相对于视口高度（1vh = 视口高的 1%），常用于大屏展示和响应式页面。

width: 25vw; width: 50vw; width: 100vw;
25vw
50vw
100vw（横滑出演示区属正常现象）

6. vmin / vmax（视口相对单位）

vmin 取视口宽、高中较小值的 1%，vmax 取较大值的 1%。适合书写在横竖屏下都协调的尺寸。

width: 20vmin; width: 20vmax;
20vmin
20vmax

7. cm / mm / in / pt / pc（绝对物理单位）

与实际物理长度对应：1in = 2.54cm = 96px，1cm ≈ 37.8px，1mm ≈ 3.78px，1pt = 1/72in，1pc = 12pt。多用于打印样式。

width: 2cm; width: 5cm; width: 1in;
2cm ≈ 75.6px
5cm ≈ 189px
1in = 96px

8. ch / ex（字体相关相对单位）

ch 相对于当前字体数字 0 的宽度，ex 相对于字体 x 的高度（x-height），常用于设定与文字排版相关的宽度。

width: 10ch; width: 20ch;

0000000000 10ch

00000000000000000000 20ch

总结

长度单位分为绝对单位（px、cm、mm、in、pt、pc）和相对单位（%、em、rem、vw、vh、vmin、vmax、ch、ex）两大类。
布局中推荐优先使用相对单位（如 %、rem、vw/vh），有利于实现响应式设计；px 适合边框、阴影等不需要缩放的细节。
