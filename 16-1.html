会改变原数组的方法

mutating · 直接在队伍上动手
push(值) 改变原数组

新元素从队尾进场，像排队时最后一个人站进来。返回值是数组的新长度。

lmh_arr.push("西瓜");
// 返回：数组的新长度
pop() 改变原数组

队尾最后一个人离开，数组少一个元素。返回值就是被删掉的那个元素。

var lmh_last = lmh_arr.pop();
// 返回：被删掉的元素
unshift(值) 改变原数组

不讲武德地插到队伍最前面，后面所有人的下标都往后挪一位。

lmh_arr.unshift("西瓜");
// 返回：数组的新长度
shift() 改变原数组

队首第一个人离开，后面所有人整体前移一位，下标全部减 1。

var lmh_first = lmh_arr.shift();
// 返回：被删掉的元素
reverse() 改变原数组

整个队伍向后转，第一个变最后一个，最后一个变第一个。

lmh_arr.reverse();
// 返回：反转后的原数组
sort(比较函数) 改变原数组

让元素按规则重新排队。这里用 localeCompare 按拼音排序，否则中文会按编码排。

lmh_arr.sort(function (lmh_a, lmh_b) {
    return lmh_a.localeCompare(lmh_b, "zh");
});
splice(起点, 个数) 改变原数组

一把剪刀，从中间剪掉若干个元素；也可以用来替换或插入。返回值是被剪掉的部分。

lmh_arr.splice(1, 1);
// 返回：被删元素组成的新数组

non-mutating · 返回值会跟着上面的数组实时变化
slice(1, 3) 返回新数组

像切面包：切下下标 1 到 3 的一段（包含 1，不包含 3），原数组毫发无伤。

把两摞盘子叠成一摞，原数组不变。参数可以是数组，也可以是单个值。

var lmh_all = lmh_arr.concat(["西瓜", "柠檬"]);

join(连接符) 返回字符串

把每个元素用“胶水”粘起来，变成一串字符串；不传参数默认用逗号。

var lmh_str = lmh_arr.join(" → ");

indexOf(值) 返回数字

问“它坐在几号位”。找到返回下标，找不到就返回 -1。

var lmh_pos = lmh_arr.indexOf("橙子");

includes(值) 返回布尔值

点名：队伍里有没有这个人？有就是 true，没有就是 false。

var lmh_has = lmh_arr.includes("葡萄");

find(条件函数) 返回元素

从前往后找第一个满足条件的人，找到就停下并交出来；找不到返回 undefined。

var lmh_hit = lmh_arr.find(function (lmh_x) {

map(加工函数) 返回新数组

每个人都进一次加工厂：这里统一加个“汁”字。新数组长度和原数组一样。

filter(条件函数) 返回新数组

一个筛子，只有满足条件的元素才能留下来，其他的被挡在外面。
