创建对象的三种方式

{ } · new Object() · 构造函数
对象字面量 最常用 
var lmh_stu = {
    name: "吕墨涵",
    age: 19
};

直接用 { } 写键值对。键名符合标识符规则时可以省略引号，值可以是任意类型。

new Object() 能用但不推荐 
var lmh_stu = new Object();
lmh_stu.name = "吕墨涵";
lmh_stu.age = 19;

先造一个空对象，再一个个挂属性。能跑，但写起来啰嗦，现代代码几乎都用字面量。

构造函数 + new 批量创建 
var lmh_Student = function (name, age) {
    this.name = name;
    this.age = age;
};
var lmh_stu = new lmh_Student("吕墨涵", 19);

把函数当“模具”，this 指向新对象，适合批量创建结构相同的对象。

对象里也能放函数

方法 · this · 调用者
方法 + this 函数也是值

属性的值可以是函数，这时叫“方法”。this 指向调用它的那个对象。

var lmh_person = {
    name: "吕墨涵",
    say: function () {
        return "我是" + this.name;
    }
};
lmh_person.say();
返回值 点下面的按钮试试
this 跟着调用者走 同一个函数

把方法“借”给另一个对象，this 就变成那个对象，不再是原来的对象。

var lmh_a = { name: "A", say: lmh_person.say };
var lmh_b = { name: "B", say: lmh_person.say };
lmh_b.say();   // 返回 "我是B"
返回值 "我是B"

函数本身不记住 this，谁调用，this 就指向谁。
