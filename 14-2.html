JavaScript 6 种基本数据类型

String · Number · Boolean · Null · Undefined · Object

← 返回首页
S String 字符串

用引号包裹的文本内容，支持单引号、双引号和模板字符串。

var lmh_str = '你好，JavaScript!';
N Number 数字

整数、浮点数、科学计数法，还包括 Infinity 和 NaN。

var lmh_num = 3.14;
B Boolean 布尔

只有两个值：true 和 false，常用于条件判断。

var lmh_flag = true;
∅ Null 空值

表示"无值"或"空对象引用"，注意 typeof null 返回 "object"（历史遗留 bug）。

var lmh_empty = null;
U Undefined 未定义

变量声明后未赋值、访问不存在的属性、函数无返回值时出现。

var lmh_x;
O Object 对象

键值对的集合，数组、函数、Date 等本质上都是 Object。

var lmh_obj = { name: '吕墨涵', age: 19 };
